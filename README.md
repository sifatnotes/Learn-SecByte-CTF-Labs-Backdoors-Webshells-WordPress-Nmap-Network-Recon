## Categories

- **Backdoor & Webshell Hunting:** Identifying suspicious webshells, backdoors, services, and persistence indicators.
- **Web Content Discovery:** Finding exposed application content and resources during authorized reconnaissance.
- **WordPress Reconnaissance:** Investigating WordPress-based applications and their exposed attack surface.
- **Apache Security:** Understanding web-server reconnaissance and suspicious server-side artifacts.
- **DNS & Hosts Configuration:** Troubleshooting name resolution and local host mappings in lab environments.
- **SSH Security:** Investigating SSH keys and access-related security issues.
- **Network Reconnaissance:** Using Nmap and Netdiscover concepts to understand network and service exposure.
- **Privilege Escalation:** Connecting discovered security weaknesses with root-access scenarios in controlled labs.

## Learning Path

A practical progression through these cybersecurity labs is:

1. Start with **Nmap and Netdiscover** for basic network reconnaissance.
2. Learn **DNS and hosts-file configuration**.
3. Practice **web content discovery** with tools such as Gobuster.
4. Explore **WordPress and Apache reconnaissance**.
5. Study **SSH keys and service enumeration**.
6. Investigate suspicious **webshells and backdoors**.
7. Finish with backdoor-focused root-access scenarios to connect reconnaissance, vulnerability discovery, and privilege escalation.

## How to Use the Labs

Use these exercises only in authorized lab environments.

Recommended workflow:

1. Read the lab objective before starting.
2. Identify the target's intended security concept.
3. Perform controlled network and application reconnaissance.
4. Document exposed services, paths, files, DNS behavior, SSH configuration, and suspicious artifacts.
5. Investigate the challenge only within the provided environment.
6. Record indicators, security impact, and potential remediation.
7. Consider defensive controls such as least privilege, secure SSH configuration, web-server hardening, file-integrity monitoring, and backdoor detection.

For webshell, backdoor, and privilege-escalation exercises, use isolated training systems and never test against systems without explicit authorization.
